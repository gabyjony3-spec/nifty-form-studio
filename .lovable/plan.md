

## Formulário de Contato com Banco de Dados

Vou criar um formulário de contato profissional que salva as mensagens no banco de dados Supabase.

### Funcionalidades

1. **Página de Contato**
   - Formulário limpo e moderno com campos para:
     - Nome completo
     - Email
     - Mensagem
   - Validação de campos (email válido, campos obrigatórios)
   - Feedback visual ao enviar (sucesso/erro)

2. **Banco de Dados (Supabase)**
   - Tabela para armazenar as mensagens de contato
   - Campos: nome, email, mensagem e data de envio
   - Configuração de segurança adequada

3. **Experiência do Usuário**
   - Mensagem de confirmação após envio
   - Indicador de carregamento durante o envio
   - Mensagens de erro claras se algo der errado

### Design
- Visual limpo e profissional
- Responsivo para funcionar em celular e computador
- Cores neutras que combinam com qualquer marca
